Android adaptation
Warzone Towers is a modified Android adaptation; its mobile interface, modes, controls and integration differ from the upstream game. References to the upstream project identify the source and contributors and do not imply endorsement. Source for this adaptation is maintained separately at https://github.com/rbabbit/wz-android . Access is restricted while that repository remains private; it is not an anonymously accessible source download. The complete source matching a distributed build must be supplied separately until accessible versioned source is provided. This notice is not a written source offer or a substitute for source delivery.

Replay viewer
Adapted from MaWay2000/boha by MM, source commit dcaf96520aa47f7a71160cae33da32e5ece1d5f0, MIT. Adaptations include focused battlefield layout, native allowlisted data proxy and Android lifecycle handling. Three.js r149 is MIT. Game models, textures and effect artwork retain the original Warzone terms rather than the viewer's MIT licence. Match/replay services are provided by Bohan / Retropaganda and MaWay2000/boha. These third-party online services are separate from the Android application.

Tower Defense and Survival
Upstream Tower Defense mod: aco4/WZmodTowerDefense, GPL-2.0-or-later, commit 5e071ac886a9adf2ecf288cd3719d1a5d0d410ac. All 18 supplied Survival files are byte-identical to this source's mod directory and EMAG configuration overlay. The original Waves package shares 14 exact files and four differing versions of the same upstream paths. The Android adaptation adds mode selection, mobile controls, wave presentation, configuration routing, rewards integration and save restoration. See original upstream licence and README.
