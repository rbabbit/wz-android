# WZ Android

Android APK downloads for the WZ Android project.

## Download

When APKs are published, find them on the [Releases page](https://github.com/rbabbit/wz-android/releases).

## Publish a new APK

1. Open the repository's [Releases page](https://github.com/rbabbit/wz-android/releases).
2. Choose **Draft a new release** (or **Create a new release**).
3. Click **Choose a tag**, enter a new version such as `v1.0.0`, and create that tag from `main`.
4. Enter a release title, such as `WZ Android v1.0.0`.
5. Drag your existing `.apk` file into **Attach binaries by dropping them here or selecting them**.
6. Wait for the APK upload to finish, then click **Publish release**.

Your APK will then be available to download from that release. You can repeat these steps for later versions.

> This repository is used to distribute APKs manually. It does not build or sign Android APKs, and no APK is included in the repository itself.
