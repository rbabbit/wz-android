# Warzone Towers 0.28 benchmark

On 9 November 2026, the user accepted the existing delivered 0.28 as the new
current benchmark for GitHub `main`, tagged `v0.28-benchmark`, and authorized a
release containing its APK and complete source ZIP. Older versions remain
preserved as fallbacks.

Promotion preserves those verified delivery files unchanged. It does not
rebuild the APK, repack the complete source ZIP, or run additional emulator
tests. Repository promotion documentation therefore postdates the frozen
source archive.

The existing verification comprises 200 JVM wallet checks, 16 strict web
fixture groups and ten focused emulator checks on the exact delivery APK.
The emulator journey covered Home and in-game purchases, a bulk allowance
increasing from one to six, one normal paid construction consuming an item,
manual saving, older/newer save loads retaining five remaining, and app
restart/load retaining wallet 50 and those five allowances. Source fixtures
and the separate supplemental automatic-save observation retain their own
scope and do not establish a full campaign or all-map gameplay pass.
