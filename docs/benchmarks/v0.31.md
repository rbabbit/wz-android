# Warzone Towers 0.31 benchmark

On 9 November 2026, the user accepted the delivered v0.31 as the new current
benchmark for GitHub `main`, tagged `v0.31-benchmark`, and authorized a release
with the existing APK, complete source ZIP and checksums. Older versions remain
available as fallbacks.

- Version name/code: `0.31` / `31`.
- Android package: `com.rbabbit.warzonetowers.lab`.
- APK: `Warzone-Towers-0.31-Test-Ads.apk`, 191,355,682 bytes.
- APK SHA-256: `93374c1a611ba2cf9bf3f999a3f42e17939bbd56dfba559395b4ef84634f03bc`.
- Complete source ZIP: `warzone-towers-0.31-source.zip`, 1,944,246,533 bytes,
  9,114 entries.
- Source ZIP SHA-256: `92827bcb97ca086606165974ddfb8da8a3be3dfa8f886508df8c8ecce01aa3fe`.
- Checksum file: `Warzone-Towers-0.31-Test-Ads-SHA256.txt`.

The benchmark includes the prominent white Research button, header menu toggles,
removal of the listed duplicate close controls, native-acknowledged Produce
feedback, a compact Gain 10 Crystals button, and removal of the blue native
map-name/time text behind the footer. Test ads remain enabled; the release does
not enable live monetized advertising.

The existing exact-APK evidence records 27 focused emulator checks. These cover
repeated header toggles, two real trucks produced by Factory 2, two research
items retained through close/reopen, a guard tower completing after Build was
closed, the published Towers consent message followed by a sample ad adding ten
crystals, native pause/resume, saving, menu returns and wallet persistence after
restart. Supporting host fixtures record 19 command and 12 navigation checks;
they are separate from actual emulator evidence. No full campaign, all-map
graphics, physical-phone or live-ad pass is claimed.

The complete source archive includes the unchanged full native base source and
the exact guarded `display3d.cpp` overlay, patch and reproduction recipe for the
two removed text draw calls. The recorded native build compiled one source
object and relinked the engine. It did not repeat a clean dependency/toolchain
build. See the [native source notes](../../archive/native-hud-0.31/README.md).

Promotion preserves the verified delivery files unchanged. It performs no APK
rebuild, source repack or additional emulator testing. Promotion documentation
and the updated repository README therefore postdate the frozen source ZIP.
