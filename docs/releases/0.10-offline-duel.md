# Warzone Towers 0.10

The app keeps Towers and adds **1v1 vs Bot** on its main menu. Choose Cannon or
Rockets before starting; the opponent uses the other branch. Research offers
the chosen weapons and shared upgrades. Destroy the opposing Command Centre.
Both bases start equally prepared, with 2,500 power. Production and subsequent
research use ordinary game costs and times. This mode runs offline.

The launcher and return confirmation use Android views. The in-game interface
continues the existing HTML/CSS interface over the Warzone WebAssembly engine.
The engine program and WASM are shared unchanged; Duel has its own generated
data package, rules, map, research policy and save directories. Its bot uses
the stock NullBot tactics with the selected weapon policy.

The phone design library is retained across modes. An incompatible design
remains saved and is unavailable in Duel. The Cannon and Rockets save folders
are separate from each other and from Towers.

The fixed Towers baseline is preserved as GitHub tag
[`v0.9-benchmark`](https://github.com/rbabbit/wz-android/releases/tag/v0.9-benchmark),
commit `28fe51dc5725d5262b0302de10776ae1a37eb994`, with its APK and complete source.
It removes STATS from the header and refines the black-and-white return dialog.
Its gameplay, maps, native program and in-game pages are retained in 0.10.
Older releases and the separate v6.4 fallback remain preserved.

See [the exact-APK verification report](../../qa/test-10/REPORT.md) for observed
gameplay, screen and preservation checks. Victory/defeat checks use disclosed
complete-save fixtures; they are separate from ordinary combat. Physical-device
rendering/FPS and audio are not newly verified. The existing software-emulator
black-terrain limitation remains.

The app keeps package ID `com.rbabbit.warzonetowers.lab` and its signing identity
to update the accepted app without removing its private designs and saves.
