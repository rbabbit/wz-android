# Warzone Towers 0.11

Towers uses the approved compact interface across Build, Research, Factory,
Design, the phone blueprint library and activity queues. The in-game interface
is HTML/CSS over the existing Warzone engine. The Android launcher, original
artwork and black-and-white return confirmation remain in place.

- Build uses complete rows with real structure pictures, names and power costs.
  Its queue and Exit remain at the bottom, while unit controls return after exit.
- Research separates facility selection from category filters and combines the
  selected topic, active lab and waiting queue into one useful side panel.
- Factory groups vehicle and cyborg facilities separately. Both strips support
  five facilities, horizontal panning and selection by actual native ID.
- Design, saved blueprints and activity pages share the same spacing, colours
  and flat rows. Blueprints remain saved privately on the phone; production
  uses unchanged game operations. No factory ETA or 3D preview is invented.

Facility counts come from the game, including five labs plus five vehicle and
five cyborg factories. Research stays manually assigned. Existing saves, phone
designs, building placement, costs, timings and camera/input behaviour remain.

The 1v1 feature is retained for later work. Its rules, map, data package and
existing interface are preserved by the Towers-only layout guard.

The complete 0.10 APK/source fallback is retained in
`C:/timerApp/fallbacks/towers-before-ui-0.11-20261108/`. The immutable GitHub
Towers benchmark and older fallbacks, including v6.4, remain preserved.

See [the verification report](../../qa/test-11/REPORT.md) and
[visual comparison](../../design-qa.md). The crowded-facility test uses a
disclosed complete native save with added facilities, while ordinary production,
designs and construction are checked separately. Software-emulator black terrain
remains a known limitation; handset GPU/FPS and audio are not newly certified.

Package ID and signing identity remain unchanged so this APK updates 0.10
without removing its private library. Version code/name are `11` / `0.11`.
