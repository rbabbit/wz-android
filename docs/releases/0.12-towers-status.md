# Warzone Towers 0.12

Towers keeps the compact 0.11 layout and adds live Research and Production
status while the battlefield is visible. The sidebars show current work from
actual native facility IDs; waiting queues remain on the full pages. Production
time and percentage are not invented.

Touching an owned, completed laboratory or factory opens the full Research or
Factory page with that actual facility selected. Vehicle and cyborg factories
remain separate, and the pages continue to support five labs plus five vehicle
and five cyborg factories. Building placement, module targeting and ordinary
unit selection/movement retain their own touch modes.

The in-game interface remains HTML/CSS over the existing Warzone engine. The
Android launcher, original icon, app name and black-and-white Return confirmation
are retained. The deferred 1v1 mode keeps its existing interface and complete
game package.

The compiled engine and WASM are unchanged. The supported scenario embed tool
appends/reindexes a read-only Towers observer for facility positions and current
production; all other indexed map, rule and game-data contents remain identical
to 0.11. No production orders, research rules, costs or timings are changed by
that observer.

The accepted 0.11 APK and complete source remain in
`C:/timerApp/fallbacks/towers-before-status-0.12-20261108/`. Older fallbacks,
the immutable GitHub Towers benchmark and separate v6.4 are preserved.

See [the exact-APK verification report](../../qa/test-12/REPORT.md) for the
actual screen/gameplay evidence and limits. The five-lab/five-vehicle/five-cyborg
case reuses a disclosed complete native save with added completed facilities;
ordinary production, construction and saves are checked separately. Software
emulator black terrain remains a known limitation; handset GPU/FPS and audio
are not newly certified.

An existing automatic truck-isolation timeout appeared in a crowded test setup.
The construction check continued with a real manual single-truck selection;
this release does not claim to fix that unchanged picker.

Package ID and signing identity remain unchanged, so this APK updates 0.11 and
retains its private phone designs and saves. Version code/name are `12` / `0.12`.
