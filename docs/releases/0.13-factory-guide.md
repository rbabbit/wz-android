# Warzone Towers 0.13

The full Towers Factory page uses the selected Option 3 layout, with vehicle
and cyborg facility selection, the available design catalogue, quantity controls
and the selected factory's current work and waiting queue. Native factory IDs,
normal production costs and the private phone design library remain in use.
Android Back closes a nested Factory queue or menu before the Factory page.

The Towers header keeps BASE and removes NEAR, BATTLE and MAP. HELP becomes a
personal how-to guide for this app's existing controls and game flow, written
from the local game and code. It does not use a web guide. Back closes the guide
and returns control to the battlefield.

The compact Research page, current-work status sidebars and world laboratory/
factory page opening remain from 0.12. The deferred 1v1 keeps its existing
interface. All Towers and Duel programs, WASM, data packages, maps and scenarios
are byte-identical to 0.12. Android code, icon, name and Return confirmation are
also retained. The in-game pages continue to use HTML/CSS over the game engine.

The accepted 0.12 APK and complete source are retained in
`C:/timerApp/fallbacks/towers-before-factory-0.13-20261108/`. Older fallbacks,
the immutable GitHub benchmark and separate v6.4 are preserved.

See [the exact-APK verification report](../../qa/test-13/REPORT.md) for the actual
Factory, production, queue, navigation and screen evidence. Maximum-facility
layout checks reuse the disclosed complete native save containing five labs,
five vehicle factories and five cyborg factories; normal production is checked
separately. Software-emulator black terrain remains a known limitation, and
physical-handset GPU/FPS and audio are not newly certified.

The package ID and signing identity are unchanged, so 0.13 updates 0.12 while
retaining private phone designs and saves. Version code/name are `13` / `0.13`.
