# Warzone Towers 0.15 — battlefield facility taps

This change focuses on opening the existing Research and Production panels by
tapping their lab or factory on the battlefield. The source changes are limited
to facility-tap routing and the building display's hit-target information.

The source audit addressed these paths:

- Open the owned, completed facility by its existing native ID immediately,
  rather than silently dropping navigation behind a fresh-state reply/time limit.
- Handle a stationary facility tap before generic long-press/combat behaviour,
  retaining the drag, box, placement and queue guards.
- Compare projected unit faces with building depth so a truck behind a visible
  roof does not veto that building's hit area.
- Resume camera observation without blocking when battlefield touch begins.

The release was reviewed in source and built as an Android APK. **No tests,
emulator sessions or gameplay/runtime checks were run for 0.15**, as requested.
The 0.14 screenshots, test reports and delivery gates remain historical evidence;
they do not establish that the 0.15 change works at runtime. Package hashes and
source ZIP CRC/SHA readback establish archive integrity only.

The existing 0.14 APK, complete source ZIP and checksums remain unchanged at
`C:/timerApp/`; their exact paths, sizes and hashes are recorded in
[archive/fallback-0.15.json](../../archive/fallback-0.15.json). No duplicate
1.87 GB fallback ZIP is needed. Older versions and v6.4 remain preserved.

The engine, maps, game rules, footer and deferred Duel mode are outside this
change's scope. The in-game interface remains HTML/CSS over the existing
WebAssembly engine. The package ID, signing line and phone storage are retained;
version code/name are `15` / `0.15`.
