# Warzone Towers 0.16 — Research selection and Help text

Research supports selecting one topic or several topics before using Add to
queue them for the chosen lab. Tap in the desired order; numbered highlights
show that order. Tap a selected topic again to deselect it, or leave just one
selected for a normal single-topic Add. The batch appends once in tap order;
if it cannot fit within the 64-item limit, selection is kept rather than partly
queued.

The existing Standard, Large and Extra Large interface-size options now scale
Help text, headings and buttons properly. They use the existing shared saved
preference, including its active state and reopening behaviour; no separate
Help-size preference is introduced.

This release received source audit/review and an Android build only. **No tests,
emulator sessions or gameplay/runtime checks were run for 0.16**, as requested.
Older release screenshots, test reports and delivery gates remain historical;
they are not current verification of these changes. APK metadata, file hashes
and source ZIP CRC/SHA readback establish packaging integrity only.

The existing 0.15 APK, complete source ZIP and checksums remain unchanged at
`C:/timerApp/`. Their paths, sizes and hashes are recorded in
[archive/fallback-0.16.json](../../archive/fallback-0.16.json), without duplicating
the 1.87 GB source archive. Older versions and v6.4 remain preserved.

The scope is the Towers Research interface and Help text sizing. The game
engine, maps, rules, footer and deferred Duel mode are retained. The package ID,
signing line and phone storage remain in place; code/name are `16` / `0.16`.
