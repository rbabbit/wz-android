# Warzone Towers 0.17 — field-menu selection

The Towers bottom-left field menu removes BOX and PATROL and adds DESELECT.
DESELECT clears unit selection/highlights while retaining existing movement,
construction and other orders. The deferred Duel interface is retained.
The action also clears selection modes/caches and guards against an older
pending selection reply restoring highlights. It sends no order cancellation.
The Towers Help copy reflects the updated menu.

This release received source audit/review and an Android build only. **No tests,
emulator sessions or gameplay/runtime checks were run for 0.17**, as requested.
Older QA reports and screenshots remain historical, not current verification.
APK metadata, hashes and source ZIP CRC/SHA readback establish packaging
integrity only.

The existing 0.16 APK, complete source ZIP and checksums remain unchanged at
`C:/timerApp/`. Their paths, sizes and hashes are recorded in
[archive/fallback-0.17.json](../../archive/fallback-0.17.json), without copying
the 1.87 GB source archive again. Older versions and v6.4 remain preserved.

The scope is the Towers field menu and selection action; game engine, maps,
rules and saved phone designs are retained. The package ID/signing line stays
the same; version code/name are `17` / `0.17`.
