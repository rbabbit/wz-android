# Warzone Towers 0.18 — Greenhaven Beginner map

Greenhaven is a third Towers map, labelled Beginner and stored under map ID
`beginner`. It adds a connected southern starting base and a separate schedule
of 15 waves intended to provide a gentle introduction. This is a proposed
difficulty target: **difficulty, native routing and complete playability have
not been verified at runtime**.

The release is limited to source audit/review and an Android build. **No tests,
emulator sessions or gameplay/runtime checks were run for 0.18**, as requested.
Source inspection and a successful build do not establish gameplay behaviour.
Older QA reports and screenshots remain historical. APK metadata/hashes and
source ZIP CRC/SHA readback establish packaging integrity only.

The new map and its scenario are separate additions. Dustfall (`td1`), Iron
Valley (`td2`), their existing wave schedule, the supplied Towers mod and the
deferred Duel mode remain preserved. A map-specific config router selects the
Beginner schedule while retaining a byte-identical original mod config for the
two existing maps. The supported data append and generated
package-index update add the new content while retaining the existing complete
data prefix. The compiled engine program body and WASM remain unchanged.

The existing 0.17 APK, complete source ZIP and checksums remain unchanged at
`C:/timerApp/`. Their paths, sizes and SHA-256 values are recorded in
[archive/fallback-0.18.json](../../archive/fallback-0.18.json); the 1.87 GB source
ZIP is referenced rather than copied again. GitHub `main` and
`v0.17-benchmark` remain the accepted 0.17 benchmark. Older versions and the
separate v6.4 fallback remain preserved.

Version code/name are `18` / `0.18`. The Android package remains
`com.rbabbit.warzonetowers.lab`, retaining the existing installed app line and
its saves/designs. Delivery names are `Warzone-Towers-0.18.apk`,
`warzone-towers-0.18-source.zip` and `Warzone-Towers-0.18-SHA256.txt`.
