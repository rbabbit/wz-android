# Warzone Towers 0.21 — map soundtracks and simpler start screen

Each of the 46 Towers maps has a fixed assignment from the existing music
catalog. All 39 available tracks are represented; seven assignments reuse a
track. Names and artists come from the original bundled album metadata. The
assignments remain stable when the game is reopened or replayed.

The top **MUSIC** button opens a compact panel with the current track, artist,
and **ON / OFF**. The preference is saved on the phone. The assigned track loops
during its battle. Sound effects and voices are independent of this player.
Music pauses when the app leaves the foreground and ends on battle exit or
return to the start screen.

The start screen offers **Download music to play in-game**. Music remains
optional; after verification, the button shows **Music ready**. The existing
download service keeps its progress, cancellation, resume and checksum checks.
The first optional download enables music only when no preference has already
been saved; an explicit saved Off remains Off. The long chooser is no longer
part of the exposed Towers flow.

The **1v1 vs Bot** entry is hidden from the start screen. Its implementation,
weapon choices, native payloads and source remain retained. A stale saved Duel
selection does not turn the start screen back into a Duel launcher.

Towers streams only its assigned track from the verified local optional pack,
using bounded byte ranges. It does not copy the full music pack into the native
engine heap at battle startup. The player uses the existing WebView audio
facility; the native engine's own music flag stays off for Towers to avoid two
music players. The old native playlist branch remains available to the dormant
Duel implementation. Original music bytes, download URL, length and checksum
remain unchanged.

All maps, scenery, wave schedules, game rules, research, production, saved
templates, native game data, compiled program body and WASM remain outside this
change. The complete 0.20 APK and source ZIP are preserved by hash reference in
[archive/fallback-0.21.json](../../archive/fallback-0.21.json). GitHub `main`,
`v0.17-benchmark`, older artifacts and v6.4 remain preserved.

Verification is restricted to source review, syntax/Android compilation and
packaging integrity checks. **No emulator, playback, UI operation, audio-focus,
or gameplay test is authorized for this revision.** Source or build checks do
not establish that those runtime behaviors work. Earlier QA reports remain
historical. The final release record must state the exact observed checks;
these notes alone do not establish completion.

The final independent source review found no remaining concrete source
defect. Its reviewed file hashes and observations are recorded in
[archive/music-0.21-source-review.json](../../archive/music-0.21-source-review.json).
The clean Android build and the focused rebuild after the final cache-state
notification change completed successfully. These checks establish compilation
and reviewed source correspondence, not audio playback or UI operation.

The package remains `com.rbabbit.warzonetowers.lab`, labelled **Warzone Towers**,
with version code 21 / version 0.21. Intended outputs are
`Warzone-Towers-0.21.apk`, `warzone-towers-0.21-source.zip` and
`Warzone-Towers-0.21-SHA256.txt`. The source ZIP includes the full retained native
source and old Duel/music chooser implementation.
