# Warzone Towers 0.24 — compact home

This revision implements the selected option 1 home layout: compact difficulty
tabs, the existing swipeable map preview and a small Play/music action row. The
duplicate heading and full-width settings rows are removed. The map catalog,
selection, original artwork and optional music download remain in place.

Optional HD/HQ graphics are removed from the app, including their home controls,
download path, archive loader and High graphics launch setting. Normal graphics
remain the only configuration. No VPS files are changed or deleted.

Verification for this revision is limited to source review, Android compilation
and package/archive integrity. The user's final instruction prohibits emulator
testing; current runtime appearance, input and gameplay are not claimed verified.
Earlier music verification belongs to the unchanged 0.23 player implementation.

The complete 0.23 APK, source ZIP and checksum file remain preserved by hash in
`archive/fallback-0.24.json`. Maps, waves, templates, game controls, native engine,
music bytes/player and dormant Duel gameplay are unchanged. The shared HTML
launchers only lose their optional HQ graphics initialization. GitHub benchmarks,
older releases and the separate v6.4 fallback remain untouched.

The package remains `com.rbabbit.warzonetowers.lab`, labelled **Warzone Towers**,
with version code 24 / version 0.24. Delivery artifacts are
`Warzone-Towers-0.24.apk`, `warzone-towers-0.24-source.zip` and
`Warzone-Towers-0.24-SHA256.txt`. The source ZIP retains complete native/map
sources and the deferred Duel implementation.
