# Warzone Towers 0.25 — rewards and match boosts

This revision adds a persistent on-phone crystal wallet, a compact rewards
screen and optional boosts chosen before a Towers match. Boosts belong to the
selected match rather than permanently altering research, units or templates.
The reward ledger guards settled matches and per-map milestone history against
duplicate payouts. Quitting does not earn a match reward.

The wallet receives a one-time starter gift of 350 crystals on existing or new
installations. A match can use at most two boost types:

| Boost | Crystal cost | Effect for this match |
| --- | ---: | --- |
| Fortress | 120 | One Cannon Fortress build; its normal 1,000 power cost still applies |
| Research | 60 | 25% faster research |
| Supply | 30 | 1,000 additional starting power |

A victory pays 60/80/100 crystals for Easy/Medium/Hard, plus 50 for the first
completion of that map. A defeat pays 20 crystals for each newly reached
ten-wave milestone on that map. Repeating an already recorded milestone does
not pay again. Victory records the reached milestones as consumed without an
additional milestone payout.

Both outcomes unload the finished engine and return to the compact Home screen
with the same map selected. A centered victory receipt or bottom-right defeat
receipt shows crystals already credited to the wallet; dismissing it does not
claim or credit the reward again. The approved visual references are retained
in `docs/ui-0.25/`; they are mockups rather than current emulator screenshots.

Verification for this revision is source review, focused source-only fixtures,
Android compilation and package/archive integrity. Emulator testing is not
authorized. Current screens, runtime rewards and gameplay are not claimed
verified; synthetic fixtures are identified separately from real game evidence.

The complete 0.24 APK, source ZIP and checksum file are retained by hash in
`archive/fallback-0.25.json`. Existing maps, authored waves, music and deferred
Duel payloads remain preserved. Native reward scripts use the supported data
append/reindex process: the compiled engine body, WASM, original data prefix and
unrelated virtual files remain frozen. No VPS files or GitHub benchmarks change.
Adding the crystal drawable renumbers two existing compiled XML resource
references. Package verification resolves those IDs to the same original
branding image and requires otherwise identical decoded XML; their source files
and image bytes remain frozen.

The package remains `com.rbabbit.warzonetowers.lab`, labelled **Warzone Towers**,
with version code 25 / version 0.25. Delivery artifacts are
`Warzone-Towers-0.25.apk`, `warzone-towers-0.25-source.zip` and
`Warzone-Towers-0.25-SHA256.txt`. The complete source ZIP includes the native
source, map sources, reward implementation and preserved Duel implementation.
