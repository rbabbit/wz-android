Warzone Towers **v0.28** is the new accepted benchmark.

Rewards now uses the approved compact native drawer on Home and in-game, with
the game's item images, direct category tabs and inline quantities. Live
purchases recover from a missing acknowledgement without a second charge, and
bulk allowances remain consistent across older/newer save loads.

SAVE in the game header and Saved Games on Home preserve the native match and
its reward identity. This version displays **v0.28** on Home and in Help. The
current game includes 46 maps, difficulty groups and optional per-map music;
the deferred Duel implementation remains hidden on Home.

This release uploads the existing verified APK and complete source ZIP
unchanged. Older benchmark tags, releases and fallback artifacts are retained.
Promotion documentation may postdate the frozen source archive.

Validation already recorded for this APK: 200 JVM wallet checks, 16 web
fixture groups and ten focused emulator checks covering Home/in-game buying,
one normal paid construction, saving, older/newer save loads and app restart.
These are bounded checks, not a full campaign or all-map gameplay pass. No
additional emulator testing was performed for this GitHub promotion.
