# Warzone Towers 0.32 — included music and compact screens

The soundtrack is now included in the APK. Its complete 114,721,578-byte archive
ships unchanged, with its original notices and licences. Map music can start on
the first launch without a network connection, an earlier downloaded pack or an
extraction step. The existing map-to-track assignments and Music On/Off control
remain; a saved Off preference is preserved.

Home no longer has music download/setup/cancel controls. The visible “Swipe maps”
instruction is removed while map counters, next/previous arrows, swipe navigation
and the actual map previews remain. Its native content can scroll on short
windows, with normal compact Play controls and measurements that accommodate
larger Android text.

The Rewards NEXT MATCH tab is removed. Owned items remain accessible through
controls in the same Rewards screen. Home purchases keep the existing behavior:
they add stock and select the newly bought quantity for a match within its normal
limits. The inline Use owned counter can adjust that selection before Play.
Removing the tab does not consume the player's whole inventory. Shared inventory,
prices, fortress limits, save identities, wave rewards and purchase acknowledgement
semantics are retained.

The packaged soundtrack is the pinned original pack: 55 original files,
including 40 Opus files and 39 catalogue track IDs. Every file hash and all 46
map assignments are checked. Whole-track responses are bounded streams from the
signed, uncompressed APK asset; Chromium still plays the local Blob and owns
later seek/loop operations. This preserves the earlier range/double-seek fix.

Only the hash-bound observations in
`qa/0.32-offline-small/focused-emulator-proof.json` establish the exact delivery
APK's runtime behavior. The report records actual physical viewport dimensions,
Android density and font scale. Offline music acceptance requires the old music
cache to be absent, network disabled, and actual media time to advance while
playing. Host stream/source checks do not establish Android decoding, touch
usability or rendered layout by themselves.

The v0.31 native engine, loader, virtual game data, all maps and scenario rules,
catalogues, deferred Duel content, wallet, save store and ad controller remain
frozen. The complete native base and its accepted v0.31 two-render-call source
overlay remain in the source ZIP. No native rebuild is part of this version.

The same app ID and signing certificate permit an update over the previous APK.
The verified v0.31 APK, complete source ZIP and checksum file remain unchanged
under `archive/fallback-0.32.json`, alongside all older fallbacks and v6.4. This
task does not promote the GitHub benchmark, modify the public privacy page or
change VPS files. Sample rewarded ads and the publisher consent setup remain.

Delivery files are `Warzone-Towers-0.32-Test-Ads.apk`,
`warzone-towers-0.32-source.zip` and
`Warzone-Towers-0.32-Test-Ads-SHA256.txt`. The APK and source are larger because
the complete soundtrack now travels with the app.
