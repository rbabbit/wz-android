# Warzone Towers 0.36 — Demolish and Intelligence

The unit controls replace SELECT/MOVE with Demolish and Intelligence. Demolish
uses selected construction trucks and the real native demolition order, including
unfinished foundations. Friendly structures are eligible; the player's Command
Centre is protected. Targeting follows existing native model/footprint geometry.
Cancellation, manual selection changes and loading invalidate pending targeting;
late replies must not reactivate the tool or recruit different trucks.

Intelligence displays completed research and the native report text, results,
unlocks and replacements that are actually available. Topics without a report
or model must remain distinguishable from topics with one. Initial-grant labels
depend on an observed fresh native starting frame; an unknown origin is not
presented as a completion earned during play. The page uses a dark presentation,
with entry from the unit controls and completed-research notices, and restores
the underlying input when closed or dismissed with Back.

The preview uses the original `renderResearchToBuffer` PIE renderer and the
original category report audio, without copying model/audio packs. A single
native `hci.cpp` extension exposes completed-only metadata and a bounded preview
slot through transient Towers-only MEMFS request/state files. It re-resolves
research entries, owns only its report stream, retires previous preview areas,
restores viewport/scissor/depth and native UI dimensions, and resets at native
initialization/shutdown. Native camera actions, research completion rules,
authored rounds, warnings, music and other sounds remain protected.

The full original native source and v0.31/v0.34/v0.35 overlays are preserved.
The successful build compiles only `hci.cpp` and performs one native link. The
first compile failed because a renderer-origin header was missing; that attempt
installed no runtime, and its log remains with the corrected build provenance.
The matched generated JavaScript/WASM pair retains the exact v0.35 private
worker-output hook, authored index and native data. Demolish integration then
appends/reindexes only `/data/mp/tests/warzone-towers-commands.js`; every original
data byte remains as a prefix and all 4,291 other resolved VFS files are checked
against the frozen v0.35 APK. No maps, native models, audio packs, catalogue,
wallet/reward policy, save codec/store or advertising SDKs are replaced.

`tools/check-intelligence-036.py` records source preservation and native lineage.
Source/VM/geometry fixtures support the implementation but do not establish
native orders, screen appearance, audio playback or touch behavior. Delivery
packaging requires root's separate emulator proof bound to the exact candidate
APK: actual selected-truck demolition, protected targets and cancellation/load
returns; completed research details; genuine native preview and original-audio
dispatch; and repeated
page/Back/input restoration. Tested viewport, density/font scale, seeded fixture
provenance and remaining limitations belong in that proof. Focused checks do not
claim every map, a complete match, physical phones or live ad serving.

Audio verification is limited to the original report/click dispatch and preserved
native audio sources. The emulator was started with `-no-audio`; there is no
claim that playback was listened to or that audible output was verified.

Root observed the exact delivery APK issuing a real Demolish order to one
selected truck and removing its target while the other three trucks retained
their state. The Command Centre stayed protected. A normally paid factory
foundation remained protected while an unselected truck was building it, then
was removed after the four workers were explicitly selected. Native F8 loading
cancelled targeting and rejected the old intent without losing completed research.

Two delivery captures and advancing native model frames/time showed the original
PIE preview rotating. Cobra completed naturally and its authored report was
opened through Reports. The fresh Composite Alloys completion notice was tapped
and opened its matching report, including read state and actual effects data.
Back and Research/Production/Help returns retired the model;
native saving worked from the report and after an archived-game resume. Root
also reviewed the 800×480, 240dpi, font-scale-1.3 captures: controls remained
visible, the panel stayed in bounds, history scrolled, keyboard Back returned
to the panel, and another Back restored gameplay input. Report-copy bounds and
its independent scroll region were checked; an actual detail-copy swipe was
not part of this observation.

Corrected setup failures remain recorded: a dead/unreachable assigned truck, an
already expired notice and a resumed opening controller correctly idle while the
fixture wrongly waited for a released phase. They are not counted as passed
delivery checks. An initial save after reinstall encountered an IndexedDB
connection-closing error; a cold restart of the exact APK then passed multiple
native saves. Storage code was not changed. Gameplay terrain remains black in
the existing emulator; units, native models, controls and authoritative state
were observable. Original app data (97 files byte for byte), display, density,
font scale and storage threshold were restored after the focused checks.

The frozen v0.35 APK, complete source ZIP and checksums are pinned by
`archive/fallback-0.36.json`. The complete source keeps original assets once,
includes native reproduction recipes, source fixtures and representative QA,
and excludes private/local caches, binary device backups and video/frame caches.
`tools/package-36-intelligence.py` verifies fallback hashes, source scope, native
lineage, exact APK assets/signing, proof/evidence hashes and every ZIP entry's
CRC/SHA. The archive must remain below the 2 GiB release-file limit.

Outputs are `Warzone-Towers-0.36-Test-Ads.apk`,
`warzone-towers-0.36-source.zip` and
`Warzone-Towers-0.36-Test-Ads-SHA256.txt`. Older versions and benchmarks remain
untouched. This task does not publish to GitHub, edit the public privacy site or
write VPS files. Rewarded advertising continues to use Google's sample unit.
