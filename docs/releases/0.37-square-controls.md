# Warzone Towers 0.37 — square unit controls

The selected third mock arranges the existing six unit controls as three
columns and two rows of square buttons, retaining the panel's outer width.
Demolish, Intelligence, All Units, Deselect, Stop and Trucks keep their existing
icons, labels and actions. The Research/Production footer remains unchanged.
The reference mock is not included as a background or substituted for controls.

This is restricted to `warzone/ui/towers-shell.css` and the exact Android version
bump. No Java, JavaScript, native source/runtime/data, maps, models, music,
wallet/save policy, advertising code, icons or fonts change. Native payloads and
every other app asset are compared byte for byte to the frozen v0.36 APK. Source
preservation enumerates all original code/assets outside documentation and QA,
and requires those protected paths in the complete archive. Earlier native and
gameplay suites are not rerun for a CSS layout change.

`tools/check-square-controls-037.py` records preservation only. Root's separate
exact-APK emulator proof must observe the three-by-two arrangement, square
geometry, retained width/footer, all six actions and compact/enlarged-text
layouts with usable input. Actual viewport, density/font scale and remaining
limits belong in that proof. This does not claim a full-match/all-map gameplay
pass or audible audio verification; existing v0.36 limitations remain recorded.

span bounds, wrapping fallback and a narrow label-size adjustment corrected it
before the final APK. Its failed capture/report remain separate from passed

research, power or positions.
