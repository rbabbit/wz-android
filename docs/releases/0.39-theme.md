# Warzone Towers 0.39 — monochrome theme

The user selected the second revised Production mock and authorized the same
black-and-white presentation across Towers. No emulator testing is authorized.
The complete delivered 0.38 APK, source ZIP and checksums are frozen by
`archive/fallback-0.39.json`; existing older artifacts remain unchanged.

## Presentation

- Shared near-black backgrounds, charcoal controls, white primary text, grey
  secondary text and white selected/primary buttons with black labels.
- Production has Units/Design/Blueprints first; category choices and numbered
  actual factory IDs share the next row. Quantity sits beside each Produce
  action. Additional factories scroll without inventing factories or changing
  native IDs, family memory, recipe aliases or existing quantity behavior.
- Matching presentation covers Home/map cards, native Rewards and owned-item
  chooser, Saved Games/delete confirmation, receipts, briefings/loading/return
  dialogs, header, Build, field controls, footer activity, main Research,
  Intelligence, Production/Design/Blueprints/Queue, Help, Music and notices.
- Original unit/research images, map previews, battlefield/minimap, player
  colours and placement overlays retain their actual artwork/semantics.
  Intelligence's native model aperture remains transparent.
- Existing compact sizes are retained outside the selected Production change.
  Controls remain live; no static mock image is used as an app screen.

## Verification and limits

The Android APK compiles. Ten focused Production source/desktop-browser checks
exercise actual rendering functions with controlled native-shaped data. Eleven
web-theme checks cover selected/disabled contrast, multi-selection, five activity
rows, dynamically injected styles and the native preview aperture. Fifteen
native-source groups verify unchanged callbacks/layout/services/art and matching
palette/contrast definitions. These are fixture/source checks, not Android UI,
GPU, real touch, playback or gameplay observations.

Source preservation and exact APK/package checks bind the delivered assets to
these reviewed files and to the unchanged native engine/data, scenarios/maps,
music, icon/art resources, save/wallet/advertising services and signing identity.
Google sample rewarded ads remain enabled. No emulator, physical-phone,
live-ad, all-map or full-gameplay pass is claimed. Android/Google-owned consent,
advertisement, volume and screenshot-sharing UI are outside the first-party
theme. Dormant Duel and hidden legacy routes are not redesigned.

## Reproduction

Use the existing Android SDK/JDK and Gradle wrapper:

```powershell
./gradlew.bat :app:assembleDebug -PadmobLiveAds=false --console=plain
node tools/check-production-ui-039.cjs
node tools/check-web-theme-039.cjs
python tools/check-native-theme-039.py
python tools/check-theme-039-preservation.py
```

The desktop fixture scripts use the installed Playwright/Chrome paths documented
in their source. The guarded `tools/package-39-theme.py` verifies exact inputs,
signature, test-ad identity, every source archive entry and frozen fallback
before emitting the APK, complete source ZIP and SHA-256 file. Packaging refuses
to overwrite existing release artifacts. GitHub, VPS, public privacy site,
v0.31 benchmark and the separate v6.4 project remain untouched.
