# Warzone Towers 0.42 — sage theme

The user selected the first sage Research mock and requested the same theme
throughout the app, keeping existing layouts and original game artwork.

## Presentation

- Light sage `#dce8cf` backgrounds, soft green `#cbdcba` controls, deeper sage
  `#b6c99e` selections, near-black `#10170c` text and readable dark secondary text.
- Native Home/map selection, Rewards and stored-item controls, Saved Games,
  receipts, loading, start/defeat captions and Return to Main Menu confirmation.
- Build/modules/construction queues, Production/Design/Blueprints, Research and
  ordered selections/queues, footer activity panels, Intelligence reports,
  Help, Music, header actions, save feedback and wave notices.
- App-owned native notices share the same compact sage surface. Google consent
  forms, ad creatives and Android system screens remain SDK/system controlled.
- Towers-only native console and power-meter colours use the same palette.
  Original world, player/placement colours, unit icons, maps and briefing art
  retain their colours.

No research rules, availability, prices, production counts, queues, movement,
construction limits, rewards, saves, music or ad serving policy are changed.
The existing package identity and certificate allow updating the current app.
Google sample rewarded ads remain enabled.

check this APK on their phone. No screen or gameplay acceptance is claimed.
