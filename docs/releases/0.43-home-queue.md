## Queue

Queue exposes compact Cancel controls for current production and waiting jobs.
Waiting removals use exact job IDs and factory identity. Cancelling the current
unit invokes the ordinary native cancellation/refund path only after validating
the owned factory and observed production identity. A stale current-unit request
must not cancel a following unit of the same type. Other factories, research
and construction orders are preserved; waiting jobs remain available to advance.
UI feedback waits for acknowledgement and refreshes authoritative state.

The native extension is scoped to Towers and built from the prepared matching
source cache. Complete source includes its exact delta, guarded recipe and
provenance; all earlier native fixes remain. Only the commands virtual file
changes inside the authored game-data package.
