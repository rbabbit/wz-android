# Warzone Towers 0.45 — game controls and footer Build

The user selected a game-control pass using the existing interface technology,
with current work preserved as fallback before changes. This is presentation
and input feedback, with no engine rewrite or conversion to Android screens.

## Controls

- Actual raster normal/selected control faces replace plain flat button fills.
  The light sage/black palette and original game icons/artwork are retained.
- Nine-slice artwork preserves compact control sizes. Pressing depresses the
  artwork by one pixel; the real button bounds do not move, so native release
  hit tests retain their existing coordinates.
- Selected, disabled, busy and keyboard-focus treatments remain distinct.
  Reduced-motion settings remove the small artwork movement.
- Existing native Home, Rewards, Saved Games and confirmation button factories
  use the same artwork without changing their layouts, labels or callbacks.
  Read-only text, item pictures and large catalogue rows are not giant buttons.

The two control images were generated with the built-in image tool and copied
unchanged into `app/src/main/assets/warzone/ui/game-controls/`. Their prompts,
dimensions, source image references and hashes are recorded in
`archive/game-controls-art-0.45.json`.

## Build location

Towers' top navigation no longer includes Build. The bottom-left action order
is Analysis, Manufacturing, Build. Build retains `wt-open-build` and invokes the
existing guarded toggle and truck-selection logic. Tapping again closes it.

The footer remains reachable during construction, overriding the old rule that
hid it. Neighbouring activity tabs use the established keep-orders exit before
opening their status panel. Full Research/Manufacturing/Help pages retain their
existing activity-footer visibility rules. Narrow docks can scroll horizontally.

## Input and sound

The feedback decorator observes presses and never issues game commands, delays
native acknowledgement or prevents pointer events. Drag/cancel/blur/hidden and
disabled states clear the pressed appearance. Compatibility and synthetic events
do not duplicate audio. Intelligence/report controls keep their existing native
sounds instead of playing an extra click over them.

The click is the original Warzone `ID_SOUND_BUTTON_CLICK_3`, copied byte-for-byte
from `/data/base/audio/sfx/interfce/beep3.ogg`. Playback respects native UI volume
and explicit mute settings and is capped at restrained gain. The game-data
package is unchanged. Provenance and the repeatable extraction tool are recorded
in `archive/control-click-0.45.json` and `tools/extract-control-click-045.py`.

## Preservation and verification

Complete delivered 0.44 APK, source ZIP and checksums were verified and pinned
before edits in `archive/fallback-0.45.json`. Native JS/WASM/data, all authored
scenarios/maps/music, prior native fixes, real-ad configuration and wallet/save
rules remain unchanged. Original item icons, Home tank and logo are retained.
Older artifacts, v6.4, GitHub benchmarks, privacy site and VPS are unchanged.

Focused actual-JavaScript source/VM checks cover Build routing, input cancellation,
mute behaviour and duplicate-audio prevention. The Android compiler and complete
APK/source integrity checks provide additional evidence. No emulator, browser,
physical-phone, native gameplay or audible playback test is performed. The
control feel and appearance remain for the user's device check; no runtime or
visual acceptance is claimed.

Exact delivery identity and source inventory are recorded in
`archive/release-0.45-source-build-only.json`.
