# Warzone Towers 0.46

The existing interface now uses the selected gently rounded rectangular controls
and a consistent black-and-white palette across the game menus and Android
screens. Normal controls are charcoal with white text; selected controls are
white with dark text. Press, disabled, busy and focus states remain distinct.

Shared backing around the header/footer controls is removed. Current layouts,
button actions, original item/world artwork, the grey Home tank, footer Build,
manual saves, reward rules, soundtrack and live-phone rewarded-ad configuration
are retained. The native console and power-meter changes are colour-only; the
current power display calculation and disabled autosaving remain intact.

The complete v0.45 APK/source/checksums are pinned in
`archive/fallback-0.46.json`. No older delivery is overwritten.

Validation is limited to focused source/VM checks, native/Android compilation,
signing, packaged-asset identity and complete-source archive checks. No emulator,
browser, Android runtime, audible playback, gameplay or ad serving was tested.
The delivered APK is for the user's phone check.
