# Warzone Towers 0.47

Intelligence shows only completed research for which the engine issued an
Intelligence report. The broader All completed tab is removed; completion
notifications and refreshed selections use the same eligibility rule. Minor
upgrades retain their normal completion notices without invented reports.
The open report list refreshes independently of the completion event.

Research imagery resolves stable topic IDs to existing original artwork rather
than guessing a filename from the display name. This corrects the MG tower's
lab/module thumbnail and related aliases; idle labs use the facility image.
Where no exact original artwork is packaged, an honest neutral symbol replaces
the unrelated laboratory fallback.

Build's sidebar shows one compact current unfinished site and its progress,
advances when it finishes, and hides the summary when no work remains. The
sidebar's EXIT KEEP ORDERS and expanded history controls are removed; footer
Build still closes it without cancelling construction. The detailed Queue
page remains available.

The Home map arrow uses readable ink for its selected white face and darker
pressed face. Navigation, map selection and control bounds are preserved.

The complete v0.46 APK/source/checksums are retained as fallback. Validation is
focused source/VM checks, Java compilation and complete package/source integrity.
No emulator, browser, Android runtime, audible playback, gameplay or ad-serving
test is performed; this APK is supplied for the user's phone check.
