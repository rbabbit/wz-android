# Warzone Towers 0.48

Fixes Intelligence closing about half a second after opening. Opening and live
heartbeat checks now compare the same authoritative native clock, rather than
comparing fresh native time against a delayed wave-display snapshot. Invalid
or absent timestamps cannot be mistaken for time zero. Real native game-load,
rewind and closed-session safeguards remain active.

Late heartbeat responses and failures cannot alter a newly reopened report.
The existing report rules, artwork, periodic refresh, model/audio paths, compact
Build summary, Home arrow, engine assets and all other behaviour are preserved.

Complete v0.47 APK/source/checksums remain available as fallback. Validation is
focused actual-JavaScript fixture checks, Java compilation and exact package/
complete-source archive integrity. No emulator, browser, Android runtime,
audible playback, gameplay or live-ad request is used.
