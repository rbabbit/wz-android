# Warzone Towers 0.49

Towers one-finger battlefield panning now forwards the latest absolute drag
position once per frame instead of every raw/coalesced touch sample. The last
held position stays active through a native rendered frame before release, so
the endpoint is not dropped. Pan coordinates stay inside the canvas; ending
a drag parks the synthetic cursor away from desktop screen-edge scrolling.

Cancellation, navigation, blur and new touch input clear pending callbacks and
release the held button. The existing native camera interpolation remains in
charge; no second easing/inertia filter is added. Other gestures, minimap,
selection, building, menus, Intelligence and game rules are retained.

Complete v0.48 APK/source/checksums remain as fallback. Validation uses the real
adapter in focused deterministic JavaScript fixtures, compilation and exact
APK/full-source integrity checks. No emulator/browser, Android gameplay, sound
or ad request is used. Actual phone smoothness remains for device review.
