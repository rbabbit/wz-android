# Warzone Towers 0.50

Corrects the v0.49 battlefield touch-pan regression. The native engine continues
to pan during its released-button frame, so moving the hidden cursor to the
centre immediately after release changed the target and jumped the camera.
The previous test model did not represent that native input state correctly.

Release/rearm now follows native frame ordering, and a new swipe cannot reuse
the old camera anchor. Initial movement is synchronous, while later raw motion
is batched to the display cadence. Captured coordinates remain bounded. Native
camera smoothing remains unchanged. A narrow Towers/Emscripten change treats
rapid middle-button camera presses as ordinary presses, allowing repeat swipes
instead of the desktop double-click state swallowing them.

The complete v0.49 and v0.48 artifacts remain as fallbacks. Native changes are
source-built with the matching incremental cache; other objects, generated
loader, authored VFS/data, maps, artwork and music remain preserved.

Device verification and exact delivery package records are stored with this
release. A JavaScript state-machine fixture is supplementary evidence, not a
replacement for checking the installed APK and native camera movement.
