# v0.52 — Towers loss notices and construction recovery

The exact installed APK passed the focused emulator journey described below.
Its SHA-256 is
`5060656addb412eeee359905b87fd93e319ee78c3698fa5f626e7b0811356f36`.
Complete v0.51 APK and source ZIP bytes remain preserved in
`archive/fallback-0.52.json`.

Towers' stock unit-loss message appeared at the top right of the native game
viewport, behind the incoming-wave card. The actual selected-player fatal-damage
event now supplies a structured notice: **Truck destroyed** or **Unit destroyed**,
followed by the actual unit name. It uses the existing compact black-and-white
notice on the left. Native death handling, score updates and loss audio remain
in their original call path; duplicate output transports do not duplicate the
notice or extend its timeout.

Construction recovery retains accepted plans when all assigned trucks die.
The remaining foundation and later queued sites show **Waiting for trucks**.
The user explicitly selects replacement construction trucks and chooses Resume;
the bridge validates that current group and the retained job context. It uses
normal native build/help-build orders, retains existing foundation progress and
FIFO order, and avoids silently recruiting distant trucks. The final candidate's
focused native recovery run completed the original foundation and both later
tower plans. Assigned trucks travelling to the current site are distinguished
from future FIFO sites, which remain queued until their turn.

Only Towers uses the new source-built native pair. The native build recompiles
`droid.cpp` and links once; the other 343 engine objects are unchanged. Towers'
data retains the complete v0.51 prefix and appends only the reviewed construction
bridge, replacing one VFS entry. The shared native pair, original Campaign and
Duel entrypoints, loaders, data and mission sources remain preserved. Campaign
does not use the new Towers loss route or construction policy. Maps, waves,
research rules, rewards, phone save storage and music are preserved.
