# v0.53 — Campaign controls, Design and manual guide

The installed APK passed seventeen focused emulator cases. Its SHA-256 is
`addecad6d7229b921f9f311ea08fe35890e9dec5b64ad1d21342f33e3079e7d1`.
The complete v0.52 APK and source ZIP are preserved in
`archive/fallback-0.53.json`.

Campaign now keeps Research first in the header. ALL COMBAT shares the existing
Base control group, preserving its persistent combat-only selection and physical
input fence. Intelligence uses the existing unit drawer and retains the original
native briefing/report screen and its explicit Back action. The current chapter
uses the bundled Towers font; an absent mission timer adds no filler text. The
Campaign header no longer reserves an empty Towers wave-card gutter.

The footer uses its content width within the viewport rather than forcing the
three activity/Build buttons into 282 CSS pixels. Campaign's empty activity
captions are **No labs** and **No factories**. All added layout selectors are
Campaign-scoped; Towers retains its accepted controls, labels and styles.

Campaign Design invalidates obsolete native validation when the Command Centre
or available components change. Reopening Design revalidates the current draft,
and responses from an earlier mission or draft context cannot restore stale
state. A missing completed Command Centre remains a real requirement and is
shown clearly. Native design compatibility, research availability, component
rules and manufacturing validation remain authoritative.

Campaign's additive mobile hook keeps original Game Guide topics available for
manual opening without automatically interrupting play with a modal guide. The
wrapper retains the original function's receiver, arguments and return value
apart from clearing its automatic-popup flag. It does not force-close native
panels or replace original mission callbacks.

The payload proof in `archive/campaign-0.53-payload.json` retains the complete
previous Campaign data prefix and replaces only the additive mobile bridge VFS
entry. Original mission bodies and includes, the native runtime body, and Towers
and Duel runtime assets remain preserved. No new native compilation is required.
