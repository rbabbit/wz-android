# v0.59 — Original Android icon

The Android launcher now uses the authentic WZ2100 steel shield already bundled
with the original game, instead of the illustrated tank. Standard and round
launchers share the original artwork, with padding for Android adaptive masks.

Artwork source: `app/src/main/assets/warzone/assets/android-chrome-192x192.png`.
The dedicated drawable is an unchanged copy; existing shared branding and splash
artwork are preserved. The application ID and signing identity remain unchanged.

The exact v0.58 APK and complete source ZIP remain preserved, with hashes in
`archive/fallback-0.59.json`. No GIF changes were made.

Validation: Android build, compiled icon resource inspection, original-artwork
pixel equality, package identity/signing and complete-source integrity. All game
assets, native runtimes, Java gameplay/UI, music, saves and rewards are frozen
to v0.58. No emulator, device, browser or live-ad testing was performed.
