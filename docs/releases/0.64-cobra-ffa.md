# v0.64 — Cobra FFA

New FFA matches use the exact Cobra AI already bundled with the engine. All
three opponents use the selected native Easy, Medium or Hard difficulty and
remain independent enemies on the original EMAG map. Stock Cobra and its
dependencies are unchanged. Existing FFA research/template restrictions and
native factory/pad limits continue to disable VTOL aircraft.

The FFA setup names Cobra. Saved and live matches show their actual bot type.
New Cobra saves carry an additive botType identity which is checked against
native AI names, script contexts, difficulty and the restored live packet.
Existing saves without that field retain NullBot; the legacy AI files and
exact native name remain available. Old archives are not rewritten or
silently converted into a different AI.

The generic compiled engine/WASM, Towers, Campaign, hidden Duel, touch controls,
maps, artwork, music, ads and reward rules remain preserved. Only the isolated
FFA package and necessary app FFA launch/save/label branches change, together
with the version. Delivered v0.63 APK and complete source are pinned through
`archive/fallback-0.64.json`.

Verification covers native Cobra identity and progress at all three
difficulties, independent hostility, VTOL restrictions, real save/load with
continuing AI, legacy NullBot saves and relevant layouts/navigation. Host
checks cover identity/tamper rejection and unchanged other-mode save routes.
Ordinary native starts and prepared phone saves are used without grants or
injected buildings. These focused checks do not establish full-match balance
or every later research/combat outcome.
