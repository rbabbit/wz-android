# v0.65 — Offline field guide

Home gains a compact Guide button below the existing mode buttons. The same
reader is available through in-game Help, preset to the current game mode.
It reads packaged reference data and never issues game orders or changes a
battle, save, design or wallet.

Research paths are the default page. Fifteen sections group weapons, upgrades,
bodies, propulsion, cyborgs, economy, sensors and defences. Each topic shows all
prerequisites, required structures, power/work costs, typed unlocks, upgrade
effects and subsequent topics. Towers and FFA use the actual multiplayer graph;
FFA marks its 24 blocked air topics unavailable and retains its two ground
prerequisite substitutions. Campaign uses its separate graph and conditional
artefact references. The guide does not claim that a listed topic is unlocked
in the current mission or provide fixed completion times.

Ten practical chapters cover the first five minutes, touch controls, building,
research/Analysis/Intelligence, Manufacturing/designs/phone blueprints, Towers,
FFA/Cobra, Campaign, saves/progression and common problems. Pages use actual
captured screens. Numbered arrows/outlines and menu focus are runtime layers
over unchanged source pixels; enlargement shows the original full screenshot.
Some emulator captures have dark terrain and are used to explain menus. The
world-controls reference is a verified user-supplied phone screenshot, labelled
with its capture provenance.

The black and white interface provides topic/help search, mode selection,
cross-links, Back history, larger reading text and screenshot zoom/panning.
All guide content, icons and pictures are packaged for offline use. The Sources
page identifies primary Warzone references and explains version differences;
numeric research values come from the bundled native data, not the older web
guide's balance values.

Scope: Home entry, a separate isolated guide WebView, the Help reader surface,
new guide assets/data and version. Native engines, scenario data, maps, input
gestures, manufacturing/construction logic, saves, music, ads and rewards remain
unchanged from delivered v0.64. The v0.64 APK and complete source are preserved
by `archive/fallback-0.65.json`.

Validation evidence is retained with the release: exact catalogue/source
checks, practical content/image checks, focused browser checks, clean-build
record and exact-delivery-APK emulator navigation/layout checks. These are
guide checks; they do not constitute a new full Campaign or AI playthrough.
