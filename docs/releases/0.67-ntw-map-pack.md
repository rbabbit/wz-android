# v0.67 — NTW-style FFA map pack

Adds 45 new FFA maps: fifteen two-player, fifteen three-player and fifteen
four-player maps. The six existing FFA maps remain unchanged under Originals.
Two-player matches use one Cobra opponent, three-player matches use two and
four-player matches use three. Easy/Medium/Hard and VTOL-off rules remain.

The new maps use spacious bases and a high-oil economy, with different base
positions, terrain layouts and approach routes. Native map records and terrain
previews are generated together from retained design inputs. Player-count
groups keep map browsing compact, while difficulty remains independent.

Each new base has a Command Centre, rear satellite uplink, four trucks, five
labs, a vehicle factory, a cyborg factory and six upgraded generators feeding
24 derricks. Eight unclaimed expansion oils per player can be supported by
building two more generators within the existing limit. Equal starting
infrastructure and connected broad ground routes are checked offline.

Map identity, player count and native save validation include the new maps.
Existing EMAG Cobra/NullBot saves and the six earlier map identities remain.
The compiled engines, stock Cobra, Towers/Campaign maps, touch controls,
soundtrack, rewards and ads are preserved.

The v0.66 APK and complete source ZIP were verified and retained before edits;
their hashes are in `archive/fallback-0.67.json`.

Per the user's explicit instruction, no emulator was used for this release.
Offline checks cover generated-map geometry and binary records, equal starting
resources, structure spacing, connected ground routes, unique layouts, native
package registration, launch/save identities and the grouped browser state.
These checks do not establish native pathfinding, live Cobra behavior, visual
rendering on a device or multiplayer balance. Those remain unverified in this
release. The delivery APK is built from the checked source and its assets and
complete source inventory are verified during packaging.
