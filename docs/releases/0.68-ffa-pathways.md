# v0.68 — Defined FFA pathways

Edits the terrain of the 45 authored FFA maps from v0.67. These are the same
maps with their existing names, IDs, dimensions, base positions, landmarks and
starting objects. This release does not implement the compact replacement
layouts shown during the earlier mockup discussion.

The earlier maps had route skeletons, but much of the surrounding ground was
also passable. Terrain banks now define the roads and approaches physically,
breaking up oversized open combat areas. Base construction yards, factory exits,
oil access and connected flank routes remain protected. No camera or unit
vision-range changes are included.

The six supplied FFA maps, Towers, Campaign, hidden Duel, compiled engines,
Cobra, difficulty and VTOL rules, touch controls, UI, save logic, soundtrack,
ads and rewards remain preserved. Existing saved games are not rewritten.
Native saved games include their own terrain, so these edited paths apply to
new matches. The save-format/source audit is recorded in
[the save terrain note](../ffa-pathways-0.68-save-terrain.md); a live reload was
not tested for this revision.

The v0.67 APK and complete source ZIP are retained unchanged; their hashes are
recorded in `archive/fallback-0.68.json`. Original v0.67 map design records and
release proofs remain in source, alongside the new v0.68 pathway edit records.

Per the user's instruction, no emulator was used. Offline checks cover map
binary readback, unchanged starting objects, connected paths and oil access,
lane clearance, flat foundations, openness reduction, native payload/preloader
integrity, APK build and complete source preservation. They do not establish
native pathfinding, live bot tactics, device rendering, visibility behavior or
gameplay balance. Those remain unverified for the edited terrain.
