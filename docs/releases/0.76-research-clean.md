# Warzone Towers 0.76 — compact Research

The approved layout applies to the shared main Research screen in Towers,
FFA, Campaign and Multiplayer. The duplicate inner Research heading and total
power, category/filter row and bottom current-lab/Up Next block are hidden.
Lab tabs keep the existing images and show only their numbers. Full Lab n
names and status remain available to accessibility services.

The catalogue uses the recovered space and scrolls for longer research trees.
Technology images, names, points, individual power costs, active/queued shading
and progress remain. Multiple ready topics can still be selected and assigned
to the chosen lab using the existing batch control. The compact screen always
shows all available topics, including when an old caller requests a category.

Only the shared Research JavaScript and stylesheet change. Footer Analysis,
Manufacturing, Intelligence, Hub, native clients, game rules and other assets
are preserved. No new research or native queue commands are introduced.

## Evidence and limits

The initial screen/code review and focused checklist are recorded in
[the audit](../../qa/research-clean-076/AUDIT.md). Host function checks use
actual shared functions with synthetic DOM/native-mailbox inputs. Browser
checks use the actual renderer, shipped CSS, fonts and artwork in host Edge.
They cover the four modes, normal/compact sizes and additional long/enlarged
content cases. The final build and package checks pin the delivered APK and
preserve the complete previous source history.

The user explicitly requested no emulator tests. These checks do not establish
Android WebView rendering, physical touch or native gameplay. The exact v0.75
APK and full source remain the fallback, identified in
`qa/research-clean-076/fallback-0.76.json`.
