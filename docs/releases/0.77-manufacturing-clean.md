# Warzone Towers 0.77 — compact Manufacturing and Queue

Manufacturing removes its inner heading/power total, Units tab, FACTORIES label,
quantity presets and bottom ready/waiting/status blocks. Vehicles/Cyborgs and
numbered factories share a compact toolbar with Design, Blueprints and options.
Design and Blueprints retain a small return arrow. The unit row shows native
current production state and known progress; its activity dot pulses only
while building. Paused/power/capacity states do not pretend to progress.

MANUFACTURE requests one selected unit. The cycle button arms continuous
manufacturing for that factory and design; when matching work is already
active or waiting it updates the live repeat policy. Repeat keeps at most one
automatic future order and uses ordinary native factory validation, costs,
time and unit limits. Explicit waiting orders retain FIFO priority. Turning
repeat off retains the current unit and removes unstarted automatic work.

Queue removes the duplicate heading/power total and OPEN/CANCEL controls. Each
factory has one STOP action which disables repeat, clears waiting orders and
cancels the validated actual native subject. A rejected native cancellation
does not falsely acknowledge a full Stop. Other factories remain independent.

Repeat policies are retained in script save state. New levels, destroyed or
transferred factories and player changes clear invalid policies. UI draft
choices do not create jobs and are cleared on session/reset changes.

## Validation and preservation

The scoped audit/checklist is in `qa/manufacturing-clean-077/audit.md`.
Actual command functions are checked with synthetic native APIs; shared UI
functions and the real browser renderer use controlled state/acknowledgement
fixtures. Normal/compact screens, multiple factories, active/waiting/repeat,
navigation and stable live action buttons are checked on the host.

Only the three command VFS entries are appended to retained game data; their
loaders point at the appended scripts. Previous data prefixes, all other VFS
entries, compiled programs, WASM, maps, research, music and Java remain frozen.
Strict packaging verifies the exact built APK and complete-source history.

No emulator tests were run, as explicitly requested. These checks do not verify
Android WebView rendering/touch or native gameplay on a device. The exact v0.76
APK and complete source remain the fallback.
