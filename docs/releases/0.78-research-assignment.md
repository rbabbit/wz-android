# Warzone Towers 0.78 — Research assignments and name editing

Main Research separates newly available technologies on the left from the
selected laboratory's current topic and ordered queue on the right. Numbered
lab selectors remain. Current research uses the real topic image and known
progress; topics assigned to any lab leave the available list. Unsubmitted
selections remain available until added to a queue.

Pending queue changes remain labelled SYNCING or NOT SYNCED until acknowledged.
A compact RETRY action can resend retained intent without duplicating it.
Confirmed removals remain visible while awaiting acknowledgement. Ordinary
research costs, unlocks, lab assignment and batch queuing remain unchanged.

Design names open in a compact editor near the top, with the field and Save /
Cancel together. Applying a name updates the current draft; the existing Save
Blueprint / Save Changes action still stores the complete design. The editor
preserves pending text during live updates and restores Design when closed.

These changes use the shared interface for Towers, Campaign, FFA and Multiplayer.
The hidden legacy Duel interface, footer Analysis, native engines, scenario
scripts, maps, saves, music, ads and unrelated screens remain unchanged.

## Checks and limitations

Focused function and host-browser checks cover available/assigned research,
multiple labs, queues and acknowledgement failures, compact layouts, current
art/progress, and name editing with simulated keyboard viewport changes.
The exact APK and complete source are checked against the preserved v0.77
fallback. See `qa/research-assignment-078/` for the scoped audit and proofs.

No emulator tests were run, as requested. Host viewport simulations do not
verify real Android keyboard behaviour, WebView rendering, physical touch or
native gameplay. The v0.77 APK/full source and all older fallbacks are preserved.
