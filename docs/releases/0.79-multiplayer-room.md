# Warzone Towers 0.79 — Multiplayer waiting room

This revision implements the approved compact waiting-room mock: player roster
on the left, room chat/composer on the right and Ready/team/spectator controls
below. It uses the current monochrome font and soft rectangle buttons.

The rebuilt Multiplayer client keeps the original 4.7.0 protocol, game data and
simulation. Its new local UI helper calls official Ready, chat, team and spectator
functions. Host permissions, downloads, opposing-team checks, free-chat/mute
policy and available slots remain authoritative. Requests are single-flight,
nonce/generation fenced and distinct from later native confirmation.

Loading, room transfer and exit stay covered until the matching native scene
is ready. The Activity caches room Back layers synchronously so a delayed JS
callback cannot produce a leave prompt over another room. Keyboard dismissal
retains its existing priority. Chat focus uses a compact top composer when a
keyboard obscures the lower screen.

Host evidence in `qa/multiplayer-room-079/` includes actual shared room DOM/CSS,
session/adapter, compiled native-helper and Java Back/cache checks. Synthetic
native replies and keyboard viewports are labelled as such.

The exact installed APK SHA256 is
`a1c425fe98063b144eae2b83165e449279e559b6acfee4e5a2c50672b5e766c0`.
Its scoped private/local-host emulator checks passed room layout, a real `/help`
server round trip, team C, player-to-spectator-and-back, IME/Send touch,
Back/options, Stay/Return/rejoin covers and Ready followed by match entry.
The Send pointer-down/blur issue was fixed and retested using actual touch.
Room/chat and match-entry/input checks used separate private-host starts.

The started match also confirmed move orders and changed native unit positions,
Stop/Deselect, camera movement, Research/Manufacturing/Queue and return to the
lobby. Existing FFA/Campaign setup navigation and Towers world/Research were
checked separately. See `emulator.json` and `verification.json` for the exact
fixture observations. No public-room chat was sent; actual unready was not tested.
Dark/black terrain also appears in retained v0.70/v0.71 and Towers emulator
captures; its underlying cause remains unverified.

Towers, Campaign, FFA, shared Research/Design/Manufacturing, all maps, saves,
rewards, ads and music remain frozen. The v0.78 APK/full source and all historical
proof/source members are preserved. No GitHub or VPS changes form part of this
revision. Physical phones and a full public multiplayer match are outside the
focused waiting-room checks.
