# Warzone Towers 0.80 — Multiplayer room polish

Multiplayer keeps one roster/chat/Ready screen while typing. Keyboard focus no
longer hides the roster/footer or moves the composer to an alternate page. The
room uses normal-density available bounds, while gameplay retains its existing
virtual viewport. Native viewport events are fenced by room generation/revision,
and keyboard dismissal restores full height rather than a stale inline size.

Chat and roster lists use touch scrolling with reading anchors preserved across
updates, resizing and keyboard changes. Send retains a stationary hit target.
A compact map button opens a preview generated by the native map renderer from
real terrain/start data. Preparation/download and privacy restrictions remain
native-authoritative; unavailable previews are labelled honestly.

Room buttons reuse the existing Warzone click clip, with the same native voice/
effects volume and mute policy. Dragging/scrolling and disabled controls do not
stack click sounds. Java permits only that exact existing OGG path; no arbitrary
audio API or additional sound asset is introduced.

The exact installed candidate APK is
`5837d90552d9ab2a675b4a7fd645fff89d8ee014f8eba6cbb86d02384cae7a1e`.
Actual checks used an isolated private host, without public-room chat:

- Natural text entry and Send kept the roster/footer visible; `/help` received
  real host replies. True finger scrolling worked in chat and the overflowing
  compact roster. A new inbound reply preserved the chat reading position.
- Room bounds were 1210x576 CSS pixels normally, 807x480 compact, and 807x219
  with the compact keyboard open. Keyboard dismissal restored the full room.
- The existing click clip produced nonzero decoded PCM in the WebView analyser
  (peak 0.03634, RMS 0.01106). Native-config mute blocked new playback; the config
  was restored. This verifies decoded playback, not a physical speaker audition.
- Built-in SkMountain 96x96 and host-downloaded EMAG_FFA 128x128 previews matched
  native RGB/canvas bytes with zero mismatches. The custom map directory was
  empty before joining; the host transferred the map. The actual downloaded
  digest is retained in `qa/multiplayer-room-080/delivery-custom-download.json`.
- Ready started a real private Cobra match. In the SkMountain match, units
  160003/160001 received native move order 2/action 1 and moved from 87,80 and
  88,80 to 87,81 and 88,81. Stop returned order 0; Deselect cleared selection.
  A real two-finger camera gesture moved 10624 to 11488, ending with zero
  pointers and no runtime errors. Back/Stay kept the game; Back/Return reached
  the custom lobby, and the next Back restored Home. Native observations and
  screenshots are retained in `delivery-gameplay-input.json/png`,
  `delivery-game-return-lobby.json/png` and `delivery-home-restored.png` under
  `qa/multiplayer-room-080/`.

Separate host evidence in `qa/multiplayer-room-080/` executes the actual Java
fit/IME/Back methods, room DOM/CSS, session/adapter and native preview helper.
Synthetic native replies, keyboard fixtures and host audio checks remain
labelled separately from the Android observations above. Delivery recording
and packaging pin those exact-APK observations and the unchanged source.

Physical phones, acoustic speaker output and a full public match were not
verified. The pre-existing dark/black emulator terrain appearance is outside
this room polish and its cause remains unverified.

Native protocol `16384/104`, official game data, room command authority, all
offline modes, shared Research/Design/Manufacturing, maps, music, ads, rewards and
saves remain frozen. The v0.79 APK/full source and all historical source/proofs
are retained. No GitHub or VPS changes are part of this revision.
