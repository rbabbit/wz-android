# Warzone Towers 0.81 — Multiplayer Lobby and player name

In Multiplayer gameplay, Lobby sits immediately after Music. The live timer
uses its own status slot so it does not separate those two buttons.

The Multiplayer name editor keeps a fixed `(m)` suffix beside an editable base
of up to twelve characters. The final nickname is at most fifteen characters.
The base name is saved for later sessions and is applied before joining a native
room. Existing names are normalized without duplicating the suffix.

This release changes only the Multiplayer header/profile UI and its Activity
storage, plus version/documentation. The native client, protocol `16384/104`,
map-preview and room authority, game data, gameplay, offline modes, shared menus,
music, ads, rewards and saves remain unchanged from0.80. The delivered0.80 APK,
complete source and every older source entry are retained as fallbacks.

Focused host/browser evidence and the exact installed-APK emulator observations
are retained under `qa/multiplayer-profile-081/`. Delivery packaging requires
those observations, current source pins, a successful build, matching signing
certificate and byte preservation of all unrelated APK/source members. It does
not rerun or claim a complete public match or unrelated gameplay regression.
The pre-existing black terrain observed in the emulator is outside these two
changes; its physical-device behavior remains unverified. No GitHub or VPS
changes are included.

The exact delivery APK was checked in the existing emulator: legacy name
migration, real Android keyboard Select All/Delete and overlong entry, fixed
suffix, saved-name cold launch, actual private-room and native-game name, and
Lobby return navigation. Lobby/Music adjacency was observed in the native game.
The private stock bot match provides no countdown, so its timer layout screenshot
uses a presentation-only `00:02:17` label with native state/orders unchanged;
normal/compact timer and connection-message wrapping also passed browser checks.
No complete public match or unrelated gameplay regression was claimed.
