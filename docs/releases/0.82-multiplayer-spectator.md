# Warzone Towers 0.82 — Home tagline and Multiplayer spectators

Home adds the exact small line “Advance Research Tech · Build & Deploy Units ·
Upgrade Structures”. Existing logo/tank artwork, six mode buttons, navigation
and version placement remain. On compact/enlarged-font layouts the line can
wrap above the logo without moving the artwork or buttons.

Multiplayer separates observer camera/rendering access from player-owned UI.
Real player identity is authoritative: watching another player's index does not
grant control of their units, facilities or research. Reserved observer slots
cannot run a private owner UI VM, poll owner data, select/lock watched units or
submit build/research/manufacturing orders. Camera/input release, read-only
chrome and return paths use the corresponding capability instead.

Audit reproduced a pre-start observer in the isolated official 4.7 two-Cobra
fixture. The v0.81 baseline eventually rendered its world after an initial CDP
wait timeout, then repeatedly attempted owner API reads at observer slot 14.
The new guard targets those invalid owner reads. It does not change official
spectator slot rules, blind-room privacy or support for joining running games.

Host evidence under `qa/multiplayer-spectator-082/` includes 1,104 Home geometry
assertions across 48 cases and 21 actual C++ capability/preservation assertions.
The native pair was rebuilt from the retained matched source; only the private
QJS UI translation unit changed. Protocol 16384/104, official multiplayer data,
simulation, renderer, room handlers and all other modes/shared interfaces remain
frozen. The complete v0.81 APK/source and every historical member are preserved.

The exact delivery APK was verified on Android by SHA-256:
`fecd9bfb968cf0a96f0e8bf978c8616dfdbe5057bf2c83ee3b5971aff82bf702`.
Actual observations used the isolated private official host:

- The spectator joined before start at native slot 14. World render frames
  advanced from 2 to 1614. Touch pan/rotation/zoom/tilt and minimap navigation
  changed native camera coordinates; this was a running rendered session.
- Native owner requests were denied and selection stayed empty. Observer game
  chrome offered Music/Lobby; repeated Music returns and Lobby Cancel/Stay/
  Return behaved correctly and returned to the app lobby.
- Normal player 0 retained native owner capability. Research with two labs,
  Manufacturing with two factories and Queue opened/closed, two trucks could
  be selected, and an actual swipe moved native camera X from 10624 to 8932.
  Return reached the app lobby.
- Home was inspected normally, at compact 640x320dp and after restoration.
  The tagline, original art and all six mode buttons fitted without overlap.

These exact-APK observations are retained separately from baseline captures and
host/synthetic fixtures under `qa/multiplayer-spectator-082/`. A full public
match, physical-phone behavior and joining an already running match were not
verified by this focused journey.
