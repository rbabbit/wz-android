# Warzone Towers 0.84 — Native landing menus

The original black landscape Home returns with the retained official logo,
grey tank and compact mode controls. Home, Campaign, Towers, FFA and the
Multiplayer room list use native Android views with consistent monochrome
controls. Guide and Hub keep their existing readers.

Campaign uses a compact chapter/action layout while retaining Continue, saved
games, video availability, download progress and cancellation. Towers places
the actual uncropped map preview on the left, with previous/next/count controls,
difficulty, real map details and a fixed Play action. Completion markers,
rewards and saves retain their existing behavior. FFA uses the same split layout
with its player groups, actual map metadata, Cobra difficulty and fixed Start
action. All 51 FFA maps, 46 Towers maps and their identities remain available.
Only the right-side facts need vertical scrolling on compact/enlarged-text
layouts; the launch controls remain separate.

The native Multiplayer list shows the real map first, room name below and
compact player counts. It retains the saved editable player name and fixed
`(m)` suffix, Hide empty filter, Refresh, Back and Join. The presentation reuses
the existing official room parser, HTTP refresh and session/Join bridges.
The waiting room, chat, Ready, map preview and game interface remain unchanged.

## Preservation

The delivered v0.83 APK and complete source were verified before edits; their
hashes are recorded in `qa/native-landings-084/fallback.json`. Every earlier
complete-source member and the v0.83 artwork remain retained. The game engines,
network protocol, data, maps, music, icon, saves, rewards and shared gameplay
interfaces are outside this update. Home and its destinations use the existing
landscape Activity lifecycle rather than the v0.83 portrait transition policy.
