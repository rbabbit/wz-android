# Warzone Towers 0.85 — Menu corrections

This update implements five requested changes to the existing landscape app:

- Home tagline: `Research Tech - Build & Deploy Units - Upgrade Structures`.
- Field Guide: remove the Mode label/dropdown and its event bindings. Contextual
  research catalogues stay intact; all practical guide chapters remain reachable.
- Campaign: remove the large Alpha campaign heading and its reserved space.
  The existing Back, CAMPAIGN title, artwork, video download and actions remain.
- Public Multiplayer list: BACK, LOBBY, and Refresh pinned at the top right.
  Existing player name, fixed `(m)` suffix, filtering, list and Join paths remain.
- Waiting-room MAP: opaque fullscreen preview over the room's header/footer,
  with map name and Close; the real map contains within the remaining space
  without cropping or stretching. Existing preview loading/privacy and Back
  handling are retained.

## Validation and limits

The Android debug build passed. Focused host checks executed the actual
Campaign layout/update logic, native Lobby header arrangement, and actual
Guide script against bundled data. They cover compact/wrapped layouts,
Guide startup, chapter routing, search/back/text size and map-containment
geometry. Package checks verify version/signature, complete source, matching
APK assets, frozen unrelated resources and immutable v0.84 fallbacks.

No emulator, device, browser, network room or gameplay testing was performed,
as requested. Host geometry/source checks do not establish real Android
rendering, input, keyboard or full-screen behavior. The user will test the APK.
The old general Guide checker has two stale expectations against unchanged
datasets (historical FFA wording and audited-release metadata); this release's
focused startup/navigation checks pass, and Guide data was not changed.
