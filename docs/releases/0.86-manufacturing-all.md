# Manufacturing ALL in v0.86

The existing cycle control is retained. A compact ALL toggle appears beside it
when category factory 1 is selected, separately for Vehicles and Cyborgs. Number
1 is the lowest native ID among the player's completed factories in that family,
matching the displayed factory numbering. Other factories and VTOL factories do
not expose ALL.

ALL arms the next MANUFACTURE tap for that recipe. It does not enqueue from a
render, refresh or toggle. One native command resolves the current owned,
completed, compatible factories of that category and adds one unit per eligible
factory. Module, research, ownership, ordinary power/unit limits and native
acceptance remain authoritative. A full peer queue is skipped and reported;
other queues are preserved. A stale first-factory request is rejected before
queue mutation. Duplicate nonces use the existing native acknowledgement cache.

With cycle enabled on MANUFACTURE, each target receives the existing bounded,
saveable per-factory repeat policy. Cycle OFF while ALL is selected clears only
that design's matching repeat policies across its eligible peers, retaining
their current units and explicit FIFO entries. Cycle ON for already queued or
active work enables the matching policies without creating additional units.
Queue STOP remains local to its named factory. ALL is a page/session scope
choice, not a permanent group: new factories join on the next explicit batch
MANUFACTURE tap. Turning ALL off returns subsequent actions to one factory;
existing native per-factory production continues until cycle OFF or STOP.

The shared UI is used by Towers, Campaign, FFA and Multiplayer. Towers and
Campaign have matching command changes; FFA retains its no-air and ended-match
guards; Multiplayer is regenerated through the existing reviewed composer.
Three offline VFS command rows are appended from the exact preserved v0.85 APK.
The original data prefixes, compiled loader bodies, WASM and every other native
virtual file remain unchanged. No native engine or Chromium rebuild is required.
