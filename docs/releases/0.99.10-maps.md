# Maps test revision 0.99.10

Version code: 110. Source backup authorized on 19 November 2026.

## Included changes

- Maps inside FFA, with the official map catalogue, search, player-count filtering, map previews, verified map downloads and local installation. Supported map sizes range from 2 to 10 players; unused slots receive bots automatically. Downloaded Maps games enable VTOL.
- Compact setup controls on the left and a full, aspect-preserving map preview on the right. Navigation uses the previous/next buttons; swipe navigation was removed. Paging retains the correct first item when the available layout height changes.
- Bot selection and Easy, Medium or Hard difficulty. Choices include Cobra, Nexus, NullBot, SemperFi, BoneCrusher, Hover AI, Turtle AI, Dumbot25a, RatBot, RatBot MG, Squeedlerbot and Wally.
- FFA or Teams. The team editor provides presets such as 3v3 (AAA BBB), and individual player-slot assignments. Team choices are retained per map. Native locked alliances and team victory rules apply; saved games retain team assignments and validate the restored configuration. Existing FFA saves remain supported.
- Launch, runtime, HUD and saved-game integration, plus the bot preparation and source-packaging scripts.

## Build and delivery status

The normal 0.99.10 APK was built successfully with `:app:assembleRelease`, using `-PplayStoreBuild=false` and the existing normal signing identity, and delivered locally for the user's testing. This is not a Google Play build. Signing keys, passwords, build caches and local app data are excluded from Git.

No emulator or other tests were run for the Teams delivery or this GitHub backup, as explicitly requested. Existing scripts and fixtures under `qa/maps-0996` and `scenario/maps-bots` are preserved historical tooling; their presence does not establish verification of this revision.

This authorization covers committing and pushing the complete Maps source. It does not authorize a VPS upload, update-feed change, GitHub APK release, or Google Play publication.
