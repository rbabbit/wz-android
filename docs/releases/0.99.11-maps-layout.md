# Maps layout 0.99.11

Version code: 111.

The Maps chooser shows a compact grid of up to three columns and four rows on spacious landscape screens, with fewer columns or rows when space or larger text requires it. The right-hand map preview keeps the complete map visible within its bounds.

Search, player filtering, pagination and settings use less vertical space. FFA/Teams, Set teams, bot and difficulty share one row when they fit and use two rows when needed. The DOWNLOAD & PLAY action remains full-width below the page controls.

The selected map, bot, difficulty and saved team assignments continue to use actual app state. Existing map downloads, launch behavior, team editing, paging arrows and save/load support are retained. No swipe navigation was added.

No tests or emulator checks were run, as requested. Runtime appearance and interaction for this revision are unverified.

The complete Maps, bots and Teams implementation is recorded in the [0.99.10 notes](0.99.10-maps.md) and remains included in this revision.
