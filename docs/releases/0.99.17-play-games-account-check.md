# Play Games account check 0.99.17

Version code: 117.

Connection and account verification now use the same fresh `getCurrentPlayer(true)` identity path. A mismatch between cached identities from different API paths was a plausible cause of the reported false account-change warning; this cause has not been confirmed on a device.

Missing, empty, stale or failed player refreshes now leave account verification unavailable and request reconnection. They do not establish that the player changed accounts. Only a valid different identity from a fresh response takes the account-switch path.

An actual switch removes only the last-account pointer. Existing account history, account partitions, saves, the 18 configured achievements and three configured leaderboards remain retained; no identity data is migrated or cleared.

No tests, QA, browser actions, emulator checks, uploads or publishing were performed. The reported device issue and runtime behavior remain unverified.
