# Play Games page 0.99.18

Version code: 118.

A small Play Games icon at the top left of Home opens the dedicated native page, opposite the existing About button. The Play Games entry is removed from About, which retains its About and licence information.

The compact dark page has a left account pane and right-hand Achievements, Leaderboards and Cloud tabs. Native star and lock icons, achievement progress bars, leaderboard timeframe choices, the top 25 scores and the player's own score use Google Play Games data inside the app. The Cloud tab retains manual backup and restore. Account-dependent actions retain authentication and privacy guards, and internal Back navigation returns through the page before leaving it. Failed or unavailable reads report that state.

The existing fresh-player account check, 18 configured achievements, three configured leaderboards and optional sign-in remain. Manual cloud backup and restore, account history and existing saves are retained. Unsupported or unavailable Google data must not be presented as a successful result.

No tests, QA, emulator checks, browser actions or uploads were performed for this revision. Live account data, page interaction and runtime behavior remain unverified.
