# 0.99.22 — quiet startup updates for both distribution channels

The Home screen retains Check for updates in both editions. The website edition
checks only the existing HTTPS VPS version feed; the Google Play edition uses the
official Play In-App Updates API to determine update availability and sends the
user to this app's Play Store listing for installation.

Each controller makes one bounded background attempt per activity session.
No checking, latest-version or network-error message is shown by the automatic
check. A newer version produces an optional Update / Later prompt only while
the resumed Home chooser is visible, with results deferred during gameplay or
other screens. Opening another screen never starts an APK download.

The website's manual update dialog, strict feed contract, download size/hash,
package/version/signing checks, and explicit Android installation approval remain.
The Play build excludes the direct APK updater and installation permission/provider.
Play Games account connection is independent of the update channel.

Version code: 122. Normal release signing retains compatibility with the existing
website APK; the Google Play AAB uses the existing private publisher upload key.
The user explicitly authorizes VPS/update-feed and GitHub publication of this build.

No tests, lint, emulator or physical-device runs are authorized or claimed.
Build success establishes compilation and packaging only; startup prompts and
store/service behavior remain unverified at runtime.
