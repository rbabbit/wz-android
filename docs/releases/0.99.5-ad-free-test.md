# Warzone Towers 0.99.5 — ad-free test

Version name: **0.99.5**. Version code: **105**.

Removed Google Mobile Ads and User Messaging Platform SDK dependencies, ad IDs,
ad consent/privacy controls, rewarded-ad buttons, and their native/JavaScript
callbacks. General privacy and About/licence information remain available.

Completed waves retain the existing **5-crystal** reward and persistent duplicate
protection. The reward amount is now an explicit constant. Existing crystal
balances, owned items, loadouts and saves are preserved; retired ad-token fields
are ignored when reading older wallet data.

The normal signed test APK was built as
`Warzone-Towers-0.99.5-Ad-Free-Test.apk`. At the user's request, no tests or
emulator checks were run for this revision. Runtime behaviour is unverified.

This Git branch backs up source only. APK/source archives, private signing
material, build outputs and caches are excluded. This note does not authorize
publication or a Google Play release.
