# Towers Lab 01: inspected scope and acceptance checks

Starting point: the exact frozen v6.4 source ZIP. The stable project and release APK/source are read-only fallbacks. Lab uses its own Android package, launcher name, icon and private data.

Observed in actual v6.4/HTML emulator captures and the corresponding code before presentation edits:

1. Global commands plus repeated page tabs/title chrome reduce battlefield and working-panel space. Use a compact global command bar and slim contextual heading, with measured responsive header height.
2. Research category filters stretch to fill the rail, while topic, selected-lab state and waiting queue have inconsistent density. Use compact scrollable filters and readable topic/queue rows; preserve manual lab control and native acknowledgements.
3. Factory and Design presentation contains oversized artwork, distant actions and weak hierarchy. Keep component images, clear selected facility/draft identity, compact controls and adjacent production actions.
4. Build already works: retain the measured complete catalogue rows, original-mesh previews, numbered queued sites, FIFO, explicit STOP/manual movement override and native minimap. Theme it without rebuilding its command paths or moving the camera.
5. Startup does not distinguish an experiment. Give Lab its own launcher identity and a polished compact startup using the existing official artwork and functioning map/music/graphics/download controls.
6. A small collapsible live activity dock can expose existing lab/factory activity while playing. It must read existing snapshots, issue no automatic research/production, hide behind full command pages and preserve map input outside its own controls.

Required checks on the exact delivery APK:

- Stable project status plus fallback APK/source hashes unchanged; both packages installed independently; isolated template/preferences stores.
- Observable fresh game readiness, actual viewport, native unit IDs/positions, reachable sites and complete ordinary native fixtures before test journeys.
- Actual construction orders/completion on both maps, including mixed sites, numbered ghosts, complete catalogue names, minimap, STOP/movement and repeated selection.
- Selected-lab isolation, manual topic assignment/queue and observed native advancement; normal factory production and native produced unit IDs.
- Design/template save/use, restart persistence, keyboard actually visible before Back, repeated page/help/native-menu returns and restored movement input.
- Wide, phone, enlarged-text screens inspected for clipping/overlap and compact usable controls. Independent scroll regions remain usable.
- Verify source/assets inside the signed delivery APK, capture actual screenshots/native evidence, package complete editable Lab source and disclose limits. No whole-game or physical-device performance claim.
